# GDGoC AITR Portal — UI/UX Audit

## Overview

I reviewed the GDGoC AITR portal on both desktop and mobile layouts. The review covered responsiveness, navigation, visual hierarchy, accessibility, event presentation, and major interactive links.

The portal provides a clean and modern interface with consistent Google/GDGoC-inspired visual styling. The major navigation links and calls to action were also tested and were functioning correctly.

---

## 1. Mobile Hero Badge Overlap

**Priority:** High  
**Platform:** Mobile  
**Category:** Responsive UI / Layout

### Observation

On the mobile layout, the location badge above the hero heading is partially obscured by the navigation/header. Only the "Indore" portion is clearly visible.

### Impact

This makes part of the hero content difficult to read and indicates that the spacing between the mobile header and hero section needs adjustment.

### Recommendation

Add appropriate top padding/margin to the hero section or adjust the header positioning so that the badge is completely visible below the navigation.

---

## 2. Statistics Cards Require Significant Vertical Scrolling

**Priority:** Medium  
**Platform:** Mobile  
**Category:** UX / Responsive Design

### Observation

The statistics section displays large cards in a single vertical column on mobile.

### Impact

The cards consume considerable vertical space and require users to scroll significantly before reaching subsequent content.

### Recommendation

Consider using a responsive two-column grid on devices where sufficient screen width is available, while retaining a single-column layout on very narrow screens.

---

## 3. Footer Typography Could Be Improved

**Priority:** Medium  
**Platform:** Desktop  
**Category:** Accessibility

### Observation

The footer contains multiple navigation and resource links, but the text is noticeably smaller than the main content.

### Impact

Small text can reduce readability, particularly for users viewing the site on smaller screens or at lower display resolutions.

### Recommendation

Increase the footer text size slightly and ensure sufficient contrast between text and its background.

---

## 4. Featured Event Information Is Relatively Dense

**Priority:** Medium  
**Platform:** Desktop  
**Category:** UX

### Observation

The featured event card presents the event image, date/time, description, organizer information, and actions within a relatively compact card.

### Impact

Important information can compete for the user's attention.

### Recommendation

Improve the visual hierarchy by giving greater emphasis to the event title, date/time, and primary action such as "View Details" or "Register".

---

## 5. Technical Topic Card Descriptions Are Small

**Priority:** Medium  
**Platform:** Desktop / Mobile  
**Category:** Accessibility / Readability

### Observation

The descriptions beneath the technical topic cards use relatively small text.

### Impact

Users may have difficulty quickly scanning the descriptions, particularly on smaller screens.

### Recommendation

Slightly increase the body-text size or shorten the descriptions so that the key information can be understood more easily.

---

# Feature Suggestions

## 6. Events Calendar / Archive

The portal could provide a dedicated events area containing:

- Upcoming events
- Event dates and times
- Registration status
- Event details
- Past events

This would allow students to discover both current and previous GDGoC activities.

---

## 7. More Detailed Chapter Lead Profiles

The chapter lead cards could include additional information such as:

- Role within GDGoC
- Area/domain of responsibility
- Professional or social profile link

This would make it easier for students to understand the chapter leadership and connect with the appropriate person.

---

## 8. Stronger "Get Involved" Pathway

The portal could make participation-related actions more prominent, such as:

- Join GDGoC
- Register for an event
- Explore upcoming events
- Access learning resources

A consistent "Get Involved" CTA across the homepage and footer could make the process easier for new students.

---

# Link and Navigation Check

The major navigation and CTA links were checked during the review.

The following areas were functioning correctly:

- Home
- Announcements
- Team
- About
- Gallery
- Contact
- Sign In
- Sign Up
- Explore Events
- View All Events
- View Details

No broken links were identified during this review.

---

# Positive Observations

The portal also has several strengths:

- Clean and modern visual design
- Consistent Google/GDGoC visual identity
- Responsive mobile navigation with a hamburger menu
- Clearly visible primary call-to-action buttons
- Good spacing between major content sections
- Mobile navigation provides easy access to all major pages
- Major navigation and interaction links were functional

---

# Conclusion

The GDGoC AITR portal provides a strong foundation with a clean, modern interface and functional navigation.

The most important improvement identified during the review is the mobile hero badge/header overlap. Additional improvements could focus on mobile content density, accessibility, event information hierarchy, and providing stronger pathways for students to discover events and get involved with the community.
